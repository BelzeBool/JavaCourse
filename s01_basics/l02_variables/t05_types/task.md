# Типы: что можно положить в сундук

В сундук для целых чисел не положишь текст, а в сундук для текста — «да» или «нет».
Пометка на сундуке называется <span class="k-term" title="Какие значения можно хранить в переменной">тип</span>.
Java проверяет её **до запуска**: положить не то не получится.

Вот шесть типов, которых хватит надолго:

<div class="k-vars">int blocks = 64; long seed = 4815162342L; double health = 17.5; boolean isNight = false; char key = 'E'; String name = "Стив"</div>

- `int` — **целое число**, примерно до ±2 миллиардов. Предметов в стаке: `64`.
- `long` — **очень большое целое**, в конце буква `L`. Сид мира: `4815162342L`.
- `double` — **дробное число**, через точку. Здоровье: `17.5` (20 — это 10 сердечек).
- `boolean` — **«да» или «нет»**: только `true` или `false`. Сейчас ночь? `false`.
- `char` — **один символ** в одинарных кавычках. Клавиша инвентаря: `'E'`.
- `String` — **текст** в двойных кавычках. Ник игрока: `"Стив"`.

<div class="k-key">

**Запомни.** `String` пишется с большой буквы, остальные пять — с маленькой. Это не опечатка:
`String` устроен иначе, чем остальные типы. Почему — узнаешь в разделе про классы. Пока просто запомни.
</div>

## Если положить не то

Java не запустит программу, а покажет ошибку. Две самые частые:

<div class="k-error">
<pre>int health = 7.5;</pre>
<pre class="k-msg">error: incompatible types: possible lossy conversion from double to int</pre>
<p><b>Перевод:</b> «несовместимые типы: при переводе из double в int часть числа может потеряться».
В сундук для целых чисел положили дробное.</p>
<p><b>Как чинить:</b> выбрать тип по значению — <code>double health = 7.5;</code></p>
</div>

<div class="k-error">
<pre>String name = 'Стив';</pre>
<pre class="k-msg">error: unclosed character literal</pre>
<p><b>Перевод:</b> «незакрытый символ». Одинарные кавычки — только для одного символа (<code>char</code>).</p>
<p><b>Как чинить:</b> текст — в двойных кавычках: <code>"Стив"</code>.</p>
</div>

<div class="k-trap">

**Ловушка: запятая.** Дробную часть отделяют **точкой**: `17.5`. С запятой `17,5` Java не поймёт.
</div>
