# Задача: карточка игрока

Команды печати уже готовы — они в редакторе ниже. Не хватает только переменных, из которых
они берут значения. Пока их нет, программа даже не скомпилируется.

## Условие

Объяви пять переменных. Для каждой выбери подходящий тип:

| Имя | Значение |
|---|---|
| `name` | Алекс |
| `level` | 30 |
| `health` | 17.5 |
| `inNether` | да (`true`) |
| `inventoryKey` | буква E |

Программа должна напечатать:

<pre class="k-console">Игрок: Алекс
Уровень: 30
Здоровье: 17.5
В Незере: true
Клавиша инвентаря: E</pre>

<div class="hint" title="Какой тип для чего">

Текст — `String`, целое число — `int`, дробное — `double`, да/нет — `boolean`, один символ — `char`.
Если забылось — таблица на шаге «Типы».
</div>

<div class="hint" title="Ошибка cannot find symbol">

`cannot find symbol` значит: команда печати зовёт переменную, которой нет. Проверь, что имя написано
точно как в таблице, с тем же регистром: `inNether`, а не `innether`.
</div>

<div class="hint" title="Решение целиком">

```java
String name = "Алекс";
int level = 30;
double health = 17.5;
boolean inNether = true;
char inventoryKey = 'E';
```
</div>
