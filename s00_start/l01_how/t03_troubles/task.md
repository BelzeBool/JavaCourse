# Если что-то сломалось

Этот шаг — справочник. Прочитай его один раз, а потом возвращайся сюда, если IntelliJ ведёт себя
странно. Почти любую проблему решает одно из действий ниже.

## Проверь, что всё работает

В редакторе открыт `Main.java`. Нажми зелёный треугольник слева от `main` и выбери **Run**.
Внизу, в окне **Run**, должна появиться строка из программы. Появилась — можно идти дальше.

## Частые проблемы

<div class="k-key">

**Первый Check долгий.** Первый раз IntelliJ скачивает Gradle и библиотеки для тестов —
это 1–3 минуты и нужен интернет. Дальше Check занимает секунды.
</div>

**Код весь красный, вверху «Project JDK is not defined».** Не выбрана Java. Открой
**File → Project Structure → Project → SDK** и выбери версию **21**. Если её нет в списке —
там же **Download JDK…**, версия 21, поставщик любой (например, Eclipse Temurin).

**«Gradle sync failed» или Check пишет про Gradle.** Открой окно [Gradle](tool_window://Gradle)
(справа на краю окна) и нажми кнопку с круговыми стрелками — **Reload All Gradle Projects**.

**Ошибки странные, хотя код точно верный.** **File → Invalidate Caches… → Invalidate and Restart.**
IntelliJ перезапустится и пересоберёт всё заново.

**Хочется начать шаг с чистого листа.** Нажми **&shortcut:SearchEverywhere;**, набери
`Reset Content` и выбери это действие: код шага вернётся к исходному.

**Не видно панели задания.** Справа на краю окна есть вкладка **Task** — нажми на неё.

## macOS и Windows

Курс работает одинаково на обеих системах. Отличается только меню настроек:
на macOS — **IntelliJ IDEA → Settings…**, на Windows — **File → Settings…**
Сочетания клавиш в тексте курса подстраиваются под твою систему сами: сейчас, например,
поиск по всему — это **&shortcut:SearchEverywhere;**.
