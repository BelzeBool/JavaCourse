# Строка не меняется — метод делает новую

Игрок вводит название предмета: `" Ruby Sword "` — с пробелами по краям и с заглавными буквами.
А в ID Minecraft можно только строчные латинские буквы, цифры и знаки `_ - . /`. Нужно `ruby_sword`.
Помогут три метода:

- `strip()` — убрать пробелы по краям;
- `toLowerCase()` — сделать все буквы строчными;
- `replace(" ", "_")` — заменить **каждый** пробел на подчёркивание. Первое в скобках — что
  искать, второе — на что менять.

## Главное: строка не меняется

Метод **не трогает** строку, у которой его вызвали. Он делает **новую** строку и возвращает её.
Если результат никуда не положить, он пропадёт. Пройди по шагам:

## Цепочка методов

Раз метод возвращает строку, у неё тоже можно вызвать метод. Тогда все три шага — одна строка:

```java
String title = " Ruby Sword ";
String id = title.strip().toLowerCase().replace(" ", "_");
System.out.println(id);
```

<pre class="k-console">ruby_sword</pre>

Методы выполняются слева направо: `strip()` даёт `"Ruby Sword"`, `toLowerCase()` — `"ruby sword"`,
`replace(" ", "_")` — `"ruby_sword"`.
