# Итог урока

<div class="k-recap">

- `+` идёт **слева направо**: пока числа — складывает, с первой строки — только склеивает.
  `1 + 2 + "3"` даёт `"33"`, `"1" + 2 + 3` — `"123"`.
- Строка — ряд клеток, номера **с нуля**. `length()` — длина, `charAt(i)` — символ из клетки `i`,
  последний — `charAt(length() - 1)`.
- `indexOf` находит, где стоит кусок; `substring(от, до)` вырезает — `до` не входит.
- `toUpperCase`, `toLowerCase`, `strip`, `replace` **не меняют** строку, а возвращают новую:
  `name = name.strip();`
- `equals`, `equalsIgnoreCase`, `startsWith`, `endsWith`, `contains` отвечают `true` или `false`.
  Строки сравнивают через `equals`.
- `String.format` и `formatted` — шаблон с пропусками: `%s`, `%d`, `%.1f`, ширина `%-10s`.
</div>

## Словарик

| Слово | Что значит |
|---|---|
| строка | текст в программе, тип `String` |
| индекс | номер клетки с символом, с нуля |
| метод | команда, которую выполняет значение: `nick.length()` |
| подстрока | кусок строки, который вырезал `substring` |
| шаблон | строка с пропусками `%s`, `%d` для `String.format` |
| текстовый блок | строка в тройных кавычках `"""`, можно в несколько строк |

## Проверь себя

<details class="k-self">
<summary>Что напечатает <code>System.out.println(2 + 2 + "2" + 2);</code>?</summary>

`422`. Первый `+` складывает два числа — 4. Дальше появляется строка, и все `+` клеят: `"42"`, потом `"422"`.
</details>

<details class="k-self">
<summary>Как достать последний символ строки <code>s</code>?</summary>

`s.charAt(s.length() - 1)`. Номера идут с нуля, поэтому последний на 1 меньше длины.
</details>

<details class="k-self">
<summary>Что вернёт <code>"minecraft:stone".substring(0, 3)</code>?</summary>

`"min"` — клетки 0, 1 и 2. Клетка 3 в кусок не входит.
</details>

<details class="k-self">
<summary>После <code>nick.toUpperCase();</code> ник остался строчным. Почему?</summary>

Метод сделал новую строку заглавными буквами, но её никуда не положили. Нужно `nick = nick.toUpperCase();`
</details>
