# Склейка: текст + переменная

В прошлой задаче на одну строку понадобилось две команды: `print` для текста и `println` для
числа. Это можно сделать одной командой — **склеить** текст и переменную знаком `+`:

```java
int diamonds = 12;
System.out.println("Алмазов: " + diamonds);
```

<pre class="k-console">Алмазов: 12</pre>

<div class="k-ru">

«Возьми текст `Алмазов: `, приклей к нему то, что лежит в `diamonds`, и напечатай».
</div>

## Как Java это считает

Java читает выражение в скобках слева направо:

1. `"Алмазов: " + diamonds` — заглядывает в сундук: там 12.
2. `"Алмазов: " + 12` — приклеивает число к тексту.
3. `"Алмазов: 12"` — получилась одна строка, её и печатает `println`.

Кусочков может быть сколько угодно:

```java
int health = 17;
System.out.println("Здоровье: " + health + " из 20");
```

<pre class="k-console">Здоровье: 17 из 20</pre>

<div class="k-trap">

**Ловушка: пробелы.** Java не добавляет пробелы сама. `"Алмазов:" + diamonds` даст `Алмазов:12`
— слитно. Пробел должен быть внутри кавычек: `"Алмазов: "`.
</div>

<div class="k-trap">

**Ловушка: числа подряд.** `"Стаков: " + 2 + 3` напечатает `Стаков: 23`, а не `Стаков: 5`.
Как только слева появился текст, `+` клеит, а не складывает. Как заставить сложить — в уроке 1.3.
</div>
