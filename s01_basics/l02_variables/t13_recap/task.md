# Итог урока

<div class="k-recap">

- **Переменная** — сундук с табличкой: у неё есть тип, имя и значение. `int diamonds = 5;`
- **Тип** решает, что можно положить: `int`, `long`, `double`, `boolean`, `char`, `String`.
- После объявления переменную зовут **по имени**, без кавычек: `println(diamonds)`.
- `=` значит **«положи»**: сначала считается правая часть, потом результат кладётся слева.
- `+=`, `-=`, `++`, `--` — короткие способы поменять число.
- `+` между текстом и переменной **склеивает**: `"Алмазов: " + diamonds`.
- `final` — константа, её нельзя поменять. Имена констант — `КАПСОМ`.
</div>

## Словарик

| Слово | Что значит |
|---|---|
| переменная | именованный «сундук» для одного значения |
| объявление | строка, которая создаёт переменную: `int diamonds = 5;` |
| тип | что можно хранить в переменной |
| значение | то, что сейчас лежит в переменной |
| присваивание | команда `=`: положить новое значение |
| константа | переменная с `final`, её не меняют |

## Проверь себя

<details class="k-self">
<summary>Что напечатает <code>int a = 2; a = a + a; System.out.println(a);</code>?</summary>

`4`. Справа `a + a` — это `2 + 2`, результат 4 кладётся обратно в `a`.
</details>

<details class="k-self">
<summary>Почему не компилируется <code>int hearts = 9.5;</code>?</summary>

В `int` можно класть только целые числа. Для 9.5 нужен `double`.
</details>

<details class="k-self">
<summary>Чем отличаются <code>'E'</code> и <code>"E"</code>?</summary>

`'E'` — один символ, тип `char`. `"E"` — текст из одного символа, тип `String`.
</details>
