# Задача: уголь для печей

Один уголь в печи переплавляет 8 предметов. Стив загружает три печи: 20 кусков сырого железа,
48 блоков песка и 5 кусков сырой говядины. Сколько угля положить в каждую?

## Условие

Количество предметов уже лежит в переменных `iron`, `sand` и `beef` — не меняй их.
Посчитай уголь для каждой печи и напечатай:

<pre class="k-console">Уголь для железа: 3
Уголь для песка: 6
Уголь для говядины: 1</pre>

Проверка посмотрит на вывод, а ещё на то, что числа 3, 6 и 1 считает программа — из переменных.

## В чём загвоздка

`iron / 8` даёт 2: целое деление округляет вниз. Но 2 угля переплавят только 16 кусков железа, а
у Стива 20 — для оставшихся четырёх нужен третий уголь. Значит, округлять надо **вверх**: если
остался хоть один предмет, нужен ещё уголь. А если предметы делятся на 8 без остатка, как 48 блоков
песка, лишний уголь не нужен.

Условий «если» мы ещё не проходили, но хватит одного сложения. Подумай: что прибавить к числу
предметов **перед** делением на 8, чтобы 16 предметов давали 2 угля, а 17 — уже 3?

<div class="hint" title="Хитрость: что прибавить">

Прибавь 7 — на один меньше, чем помещается в один уголь: `(iron + 7) / 8`.
Проверь на бумаге: 16 + 7 = 23, 23 / 8 = 2. А 17 + 7 = 24, 24 / 8 = 3. Любой остаток от 1 до 7
вместе с семёркой «дотягивает» до следующей восьмёрки, а нулевой — нет.
</div>

<div class="hint" title="Для песка получается 7">

Похоже, к результату прибавляется 1: `sand / 8 + 1`. Так уголь добавляется всегда, даже когда
48 блоков делятся на 8 ровно. Прибавлять надо к предметам до деления: `(sand + 7) / 8`.
</div>

<div class="hint" title="Угля получается 20, 48 и 5">

Похоже, нет скобок: `iron + 7 / 8`. Деление считается раньше сложения, а 7 / 8 в целых числах — 0.
Возьми сумму в скобки: `(iron + 7) / 8`.
</div>

<div class="hint" title="Печатается 3.0 вместо 3">

Похоже, тут `Math.ceil` — он округляет вверх, но даёт `double`. Хитрость с семёркой обходится без
дробей: `(iron + 7) / 8` — целое число.
</div>

<div class="hint" title="Решение целиком">

```java
int ironCoal = (iron + 7) / 8;
int sandCoal = (sand + 7) / 8;
int beefCoal = (beef + 7) / 8;
System.out.println("Уголь для железа: " + ironCoal);
System.out.println("Уголь для песка: " + sandCoal);
System.out.println("Уголь для говядины: " + beefCoal);
```
</div>
