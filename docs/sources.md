# Источники для уроков

Правило: **ничего не копируем**, только пересказываем своими словами, со своими примерами
в тематике Minecraft. Из источников берём факты, порядок тем и идеи типов задач.

Колонка «Проверено» показывает, как я проверил источник 06.10.2026:
**репо** — читал исходники на GitHub; **поиск** — сайт из облачной сессии закрыт
сетевой политикой, свежесть подтверждена поиском. Ссылки рабочие, но содержимое «поиск»-источников
перед написанием урока стоит открыть самому.

## Как работаем с источниками

1. Перед уроком открываем 1–2 источника по теме и выписываем **факты** (правила языка, сигнатуры, числа).
2. Пишем урок сами: свои примеры, свой сюжет в Minecraft, своя последовательность внутри урока.
3. Код мод-уроков сверяем с репозиторием Fabric Docs **на ту версию игры, под которую курс** —
   имена в Minecraft меняются почти каждый релиз.
4. Источник конкретного факта, в котором можно засомневаться, оставляем комментарием в
   `task.md` (`<!-- JLS 15.17.2 -->`). Ученик его не видит, а нам пригодится при обновлении.
