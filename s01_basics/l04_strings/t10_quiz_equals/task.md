# Вопрос: где true?

В переменной лежит название предмета — с заглавными буквами:

```java
String item = "Diamond_Sword";
```

**Какие выражения дадут `true`?** Выбери все подходящие.

Проверяй каждое по двум признакам: совпадает ли регистр букв и нет ли лишних пробелов.
