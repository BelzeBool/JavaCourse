# Итог урока

<div class="k-recap">

- **Программа** — команды, которые выполняются строго сверху вниз.
- Весь код живёт внутри **класса** `Main`, выполнение начинается с метода **`main`**.
  Первые две строки пока пишем как готовую «шапку» — `psvm` + Tab.
- `System.out.println(...)` печатает и переводит строку, `System.out.print(...)` — печатает
  и оставляет курсор на месте. Быстро набрать: `sout` + Tab.
- Текст — в **двойных кавычках**, команда заканчивается **`;`**, фигурные скобки — **парами**,
  **регистр** важен.
- Особые символы в тексте: `\n` — новая строка, `\"` — кавычка, `\\` — обратный слеш.
- **Комментарии** Java пропускает: `//` до конца строки, `/* … */` — всё между скобками.
- Ошибки компилятора читаем **с первой**: файл, номер строки, что не так.
</div>

## Словарик

| Слово | Что значит |
|---|---|
| программа | список команд для компьютера |
| класс `Main` | «коробка», в которой лежит весь код программы |
| метод `main` | точка входа: с него начинается выполнение |
| компиляция | проверка и перевод программы до запуска |
| экранирование | `\` перед символом: «следующий символ особенный» |
| комментарий | текст для людей, Java его пропускает |

## Проверь себя

<details class="k-self">
<summary>Что напечатает <code>System.out.print("A"); System.out.println("B"); System.out.print("C");</code>?</summary>

Две строки: `AB`, потом `C`. После `print("A")` курсор остаётся в строке, `println("B")` дописывает
`B` и переводит строку, `print("C")` начинает новую.
</details>

<details class="k-self">
<summary>Как напечатать <code>Путь: C:\games</code>?</summary>

`System.out.println("Путь: C:\\games");` — обратный слеш в тексте пишется дважды.
</details>

<details class="k-self">
<summary>Компилятор выдал четыре ошибки. С какой начать?</summary>

С первой. Остальные часто — «эхо» первой: почини её, запусти снова, и часть ошибок исчезнет.
</details>
