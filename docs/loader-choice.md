# Fabric или NeoForge для Minecraft 1.21.1

Сравнение под твою задачу: **новичок, хочешь научиться и сделать свой мод на 1.21.1**.
Данные на **6 октября 2026**. Документацию обоих загрузчиков я читал по исходникам на GitHub:
[FabricMC/fabric-docs](https://github.com/FabricMC/fabric-docs) (папка `versions/1.21.1`) и
[neoforged/Documentation](https://github.com/neoforged/Documentation) (папка `versioned_docs/version-1.21.1`).

> Раньше этот файл сравнивал загрузчики под Minecraft 26.3. После решения делать курс на 1.21.1
> сравнение пересчитано: многие аргументы поменялись.

---

## Что важно знать про 1.21.1

1. **Нужен JDK 21.** Курс и так на нём, менять ничего не надо.
2. **Игра обфусцирована**, как все версии до 26.1: внутри jar-файла классы называются `a`, `b`, `c`.
   Загрузчик при сборке переименовывает их в понятные имена («маппинги»).
   - NeoForge использует **официальные имена Mojang** (+ Parchment для имён параметров).
   - Fabric по умолчанию предлагает **Yarn** (свои имена), но умеет и Mojang. **Документация Fabric
     для 1.21.1 написана на именах Mojang** (`BuiltInRegistries.ITEM`, `ResourceLocation`).
   - В курсе берём **имена Mojang** при любом загрузчике. Тогда примеры из документации обоих
     загрузчиков совпадают, а код потом проще переносить на новые версии.
   - ⚠️ Многие туториалы для Fabric 1.21.1 написаны на Yarn (`Registries.ITEM`, `Identifier`).
     Ученика об этом надо предупредить, иначе чужой пример «не компилируется».
3. **Обе ветки живые.** Ветка `1.21.1` в NeoForge получила коммит 06.10.2026 (последняя версия
   из поиска — 21.1.256), Fabric API для 1.21.1 — `0.116.17+1.21.1`, ветка обновлялась 01.09.2026.
   Значит, за время курса 1.21.1 не «умрёт».

## Сравнение

| Критерий | Fabric (1.21.1) | NeoForge (21.1.x) |
|---|---|---|
| **Документация** | 45 страниц, **все 45 переведены на русский**. Примеры взяты из рабочего мода в репозитории | 63 страницы, только английский. Подробнее про устройство игры: реестры, данные, сеть, GUI |
| **Имена классов** | Mojang (в документации), но шаблон и чужие туториалы часто на Yarn | Mojang всегда, путаницы нет |
| **Сообщество на 1.21.1** | Большое, особенно моды на производительность и небольшие моды | **Главная версия для больших сборок** (ATM10 и подобные). Больше контентных модов |
| **Первая сборка** | Быстрая | Дольше: NeoForge пропатчивает исходники игры |
| **Регистрация предмета** | `Registry.register(BuiltInRegistries.ITEM, id, new Item(...))` в статическом поле — «положи объект в реестр» | `DeferredRegister.Items` + `DeferredItem<Item>`, обращение через `.get()` — нужно понимать обобщения и `Supplier` |
| **События** | Колбэки Fabric API: `PlayerBlockBreakEvents.AFTER.register((...) -> ...)` | Шина событий: `@SubscribeEvent`, `@EventBusSubscriber` |
| **Тесты мода** | `fabric-loader-junit`: JUnit с настоящими реестрами (описано в документации 1.21.1). Серверные GameTest через Fabric API | ModDevGradle: `neoForge { unitTest { enable() } }`, можно поднять тестовый сервер. GameTest описан в документации 1.21.1 |
| **Сложность первого мода** | 1–2 класса Java + модель, перевод, текстура | Столько же файлов, но в Java больше «клея»: регистр, подписка на шину мода |
| **Kotlin потом** | `fabric-language-kotlin` | Kotlin for Forge |

### Что это значит для курса

- **Порог по Java к разделу «Первый мод».** На Fabric первый предмет — это классы, статические поля
  и вызов метода: всё будет пройдено к этому моменту. На NeoForge сразу нужны `Supplier`,
  обобщения и лямбды из глав 5–6, их придётся давать «заклинанием».
- **Русская документация.** Для 1.21.1 у Fabric переведено всё. Это большой плюс для сверки.
- **Проверка мод-чекпоинтов.** Оба умеют JUnit с классами игры. У Fabric это описано прямо в
  документации нужной версии, у NeoForge — в README плагина сборки.
- **Перспектива.** Если цель — моды для больших сборок, NeoForge на 1.21.1 сильнее.
  Переход с одного загрузчика на другой с именами Mojang — это замена «клея», а не переучивание.

## Рекомендация

**Fabric (с именами Mojang)** — для курса и первого мода. Причины: ниже порог по Java к первому
моду, полная русская документация 1.21.1, тесты описаны в документации, быстрая сборка.

**NeoForge** — если тебе важнее делать моды для больших сборок или в них играют твои друзья.
Тогда в главе «Первый мод» появится один урок-заклинание про `Supplier` и `DeferredRegister`.

Есть и **третий вариант**: курс на Fabric, а в последней главе — урок «переносим мод на NeoForge».
С именами Mojang это пара часов работы, и ученик увидит, что загрузчик — это только обёртка.

Решение за тобой.
