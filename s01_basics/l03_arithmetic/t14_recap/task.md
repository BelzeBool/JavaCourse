# Итог урока

<div class="k-recap">

- `*` — умножение, `/` — деление, `%` — остаток от деления: `200 / 64` → 3 стака, `200 % 64` → 8 блоков сверху.
- Порядок: сначала скобки, потом `*`, `/`, `%`, потом `+` и `-`. Знаки одного уровня — слева направо.
- Скобки чинят склейку: `"Стаков: " + (2 + 3)` → `Стаков: 5`.
- Деление двух целых — целое: дробь отрезается. `30 / 20` → 1, `30 / 20.0` → 1.5.
- Приведение типа — тип в скобках: `(double) fuse / 20` → 1.5, `(int) 1.99` → 1.
- `Math`: `max`, `min`, `abs`, `round`, `sqrt`, `pow`. `sqrt` и `pow` дают `double`, `round` — `long`.
- В `int` помещается до 2 147 483 647. Больше — переполнение; нужен `long`: `days * 24000L`.
- Округлить вверх без условий: `(items + 7) / 8`.
</div>

## Словарик

| Слово | Что значит |
|---|---|
| остаток | что осталось после деления нацело: `150 % 64` → 22 |
| целое деление | деление двух целых чисел, дробь отрезается |
| приведение типа | тип в скобках перед значением: `(double) fuse` |
| переполнение | результат не помещается в тип и «перескакивает» на другой край |
| `Math` | готовый набор формул: корень, степень, округление |

## Проверь себя

<details class="k-self">
<summary>Что напечатает <code>System.out.println(17 % 5);</code>?</summary>

`2`. Пятёрка помещается в 17 три раза — это 15, сверху остаётся 2.
</details>

<details class="k-self">
<summary>Что напечатает <code>System.out.println(10 - 4 / 2);</code>?</summary>

`8`. Деление раньше вычитания: 4 / 2 = 2, потом 10 − 2 = 8.
</details>

<details class="k-self">
<summary>Почему <code>double half = 7 / 2;</code> кладёт в сундук 3.0, а не 3.5?</summary>

Правая часть считается первой, а там два целых числа — деление целое, 7 / 2 = 3. Только потом 3
становится 3.0. Нужно `7 / 2.0`.
</details>

<details class="k-self">
<summary>Сколько угля нужно на 64 предмета по формуле <code>(n + 7) / 8</code>?</summary>

`8`. 64 + 7 = 71, а 71 / 8 = 8 — целое деление отрезает дробь. 64 делится на 8 ровно, лишний уголь не нужен.
</details>
