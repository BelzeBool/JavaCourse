# Вопрос: что стало с зомби?

Программа готовит подпись над мобом:

```java
String mob = "zombie";
mob.toUpperCase();
String title = mob.replace("z", "Z");
System.out.println(mob + " " + title);
```

**Что напечатает программа?**

Следи за тем, что лежит в `mob` после каждой строки. Код открыт в редакторе — после ответа
запусти его и сравни.
