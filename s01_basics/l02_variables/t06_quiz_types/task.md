# Вопрос: что не так с типом?

Алекс записала в программу пять переменных. **Какая строка не скомпилируется?**

```java
int blocks = 64;
double health = 17.5;
boolean isNight = "нет";
char key = 'E';
String name = "Алекс";
```

Выбери вариант и нажми **Check**. После ответа можешь проверить себя в редакторе:
там подозрительная строка закомментирована. Убери `//` перед ней и посмотри, что скажет Java.
