# Задача: стаки

Стив накопал 200 блоков земли и раскладывает их по слотам. Сколько выйдет полных стаков по 64
и сколько блоков останется?

## Условие

1. Объяви переменную `blocks` типа `int` со значением `200`.
2. Посчитай число полных стаков знаком `/`, а остаток — знаком `%`.
3. Напечатай две строки:

<pre class="k-console">Полных стаков: 3
Остаток: 8</pre>

Числа 3 и 8 считает программа, а не ты. В коде их быть не должно — ни в вычислениях, ни в тексте
в кавычках. Ещё проверка посмотрит, что в коде есть `blocks /` и `blocks %`.

<div class="hint" title="Как напечатать результат">

Положи результат в переменную и приклей её к тексту, как в уроке 1.2:

```java
int stacks = blocks / 64;
System.out.println("Полных стаков: " + stacks);
```
</div>

<div class="hint" title="Остаток получается 64">

Порядок чисел важен. `blocks % 64` — остаток от деления blocks на 64. А `64 % blocks` — наоборот:
200 не помещается в 64 ни разу, и в остатке все 64.
</div>

<div class="hint" title="Решение целиком">

```java
int blocks = 200;
int stacks = blocks / 64;
int rest = blocks % 64;
System.out.println("Полных стаков: " + stacks);
System.out.println("Остаток: " + rest);
```
</div>
