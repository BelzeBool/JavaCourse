# Вопрос: 10 или 73?

Алмазный меч бьёт на 7, зачарование «Острота V» добавляет ещё 3. Программа печатает урон
два раза — через «и»:

```java
int sword = 7;
int bonus = 3;
System.out.println(sword + bonus + " и " + sword + bonus);
```

**Что напечатает программа?**

Иди по знакам `+` слева направо, как в разборе на прошлом шаге. Код открыт в редакторе — после
ответа запусти его и сравни.
