# Принятые решения

Короткий список того, что уже решено. Если решение меняется — правим здесь и пишем дату.

| Что | Решение | Когда |
|---|---|---|
| Формат | Курс для плагина JetBrains Academy в IntelliJ IDEA: теория в панели, задачи с кнопкой Check | с начала |
| Язык курса | Русский, к ученику на «ты», без глаголов прошедшего времени с родом | с начала |
| Подача | Текст, схемы, картинки и интерактивные схемы в панели задания. Видео нет | с начала, интерактив — 06.10.2026 |
| Уровень | С полного нуля | с начала |
| **Версия Minecraft** | **1.21.1** — не старая и не самая новая; на ней живут большие сборки модов, оба загрузчика её поддерживают | 06.10.2026 |
| **Java** | **JDK 21** — его требует Minecraft 1.21.1. Сборка курса работает и на JDK 25 | 06.10.2026 |
| **Первая программа** | Классическая: `public class Main` + `public static void main(String[] args)` + `System.out.println` | 06.10.2026 |
| **ОС учеников** | macOS (автор) и Windows. Горячие клавиши — через `&shortcut:…;`, плагин подставит раскладку ученика. Инструкции по установке — для обеих ОС | 06.10.2026 |
| **Темп** | Свой: «сел и прошёл, сколько хочется». Никаких «дней» и расписаний; урок можно бросить на любом шаге | 06.10.2026 |
| **Git** | Отдельный короткий раздел перед первым модом | 06.10.2026 |
| **Агент-заказчик** | Эксперимент: после главы — «заказ» мини-программы или мода, ИИ-агент играет клиента и принимает работу. См. `docs/agent-client.md` | 06.10.2026 |
| Загрузчик модов | **Не выбран.** Рекомендация — Fabric, см. `docs/loader-choice.md` | ждёт решения |
| Картинки | SVG из `tools/images.py`, у каждой есть тёмная версия `*_dark.svg` | 06.10.2026 |
| Как писать уроки | По руководству `docs/lesson-design.md`; эталон — урок 1.2 | 06.10.2026 |
