# Склейка: слева направо

В уроке 1.2 была ловушка: `"Стаков: " + 2 + 3` печатает `Стаков: 23`, а не `Стаков: 5`. В уроке 1.3
её чинили скобками. Теперь разберём, **почему** так выходит, — и склейка больше не удивит.

Текст в кавычках программисты называют <span class="k-term" title="Текст в программе: значение типа String, например &quot;Стив&quot;">строкой</span>.
Отсюда и имя типа: `String` по-английски — «строка». Весь этот урок — про строки.

## Правило: слева направо

Знак `+` умеет две вещи: **складывать** числа и **склеивать** строки. Java решает это для каждого
`+` отдельно и идёт **слева направо**. Каждый `+` смотрит на то, что у него слева и справа:

- с обеих сторон числа — складывает;
- хоть с одной стороны строка — склеивает. Получается тоже строка.

```java
System.out.println("1" + 2 + 3);
System.out.println(1 + 2 + "3");
```

<pre class="k-console">123
33</pre>

Разберём по шагам:

1. `"1" + 2` — слева строка, клеим: `"12"`. Потом `"12" + 3` — опять строка слева: `"123"`.
2. `1 + 2` — два числа, складываем: `3`. Потом `3 + "3"` — справа строка, клеим: `"33"`.

<div class="k-key">

**Запомни.** Пока по дороге только числа — `+` складывает. С первой строки и до конца — только
склеивает. Нужно сложить после строки — бери скобки: `"Урон: " + (7 + 3)`.
</div>

## А умножение?

`*`, `/` и `%` выполняются раньше `+` — это из урока 1.3. Поэтому `"Урон: " + 2 * 3` напечатает
`Урон: 6`: сначала умножение, потом склейка. А вот минус стоит в одном ряду с плюсом, и слева
направо выходит беда:

<div class="k-error">
<pre>System.out.println("HP: " + 20 - 5);</pre>
<pre class="k-msg">error: bad operand types for binary operator '-'</pre>
<p><b>Перевод:</b> «неподходящие типы для оператора <code>-</code>». Сначала выполняется <code>"HP: " + 20</code> — получается строка <code>"HP: 20"</code>. Отнять 5 от строки нельзя.</p>
<p><b>Как чинить:</b> скобки — <code>"HP: " + (20 - 5)</code>.</p>
</div>
