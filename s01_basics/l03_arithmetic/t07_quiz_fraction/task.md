# Вопрос: где получится 2.5?

Стив ломает 5 блоков за 2 секунды. Сколько блоков в секунду? По-честному — 2.5. Но в Java так
получится не в каждой записи.

**Какие выражения дадут 2.5?** Отметь все подходящие.

```java
5 / 2
5.0 / 2
5 / 2.0
(double) 5 / 2
(double) (5 / 2)
```

Выбери варианты и нажми **Check**. В редакторе все пять выражений напечатаны — после ответа запусти
и проверь себя.

<div class="hint" title="Как рассуждать">

Для каждого выражения спроси: в тот момент, когда Java делит, хотя бы одно из двух чисел дробное?
Если оба целые — дробь отрезается. И помни, что скобки считаются первыми.
</div>
