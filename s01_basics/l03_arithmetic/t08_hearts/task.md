# Задача: почини сердечки

Здоровье в Minecraft считают в очках: одно сердечко — 2 очка, полное здоровье 20 очков — это
10 сердечек. У Стива 17 очков. Программа должна показать, сколько это сердечек, но в ней **две ошибки**.

## Условие

Почини программу так, чтобы она напечатала:

<pre class="k-console">Сердечек: 8.5
Полных сердечек: 8</pre>

Строку `int health = 17;` и тексты в кавычках не меняй. Числа 8.5 и 8 считает программа из `health`:
готовыми в коде их быть не должно.

Первая ошибка не даст программе даже скомпилироваться. Нажми **Check** и начни с неё.

<div class="hint" title="Ошибка possible lossy conversion from double to int">

«При переводе из double в int часть числа может потеряться». Java не отрезает дробь молча: в сундук
`int` дробное число просто так не положить. Попроси об этом явно — приведением типа `(int)`.
</div>

<div class="hint" title="Печатается 8.0 вместо 8.5">

Посмотри на деление в строке с `hearts`. Оба числа там целые? Вспомни трассировку с крипером:
сундук `double` слева не спасает, если деление справа целое.
</div>

<div class="hint" title="Полных сердечек печатается 8.5">

Похоже, у `fullHearts` теперь тип `double` — ошибка ушла, но полных сердечек 8, а не 8.5.
Верни тип `int` и попроси отрезать дробь: `(int) hearts`.
</div>

<div class="hint" title="Решение целиком">

```java
int health = 17;
double hearts = health / 2.0;
int fullHearts = (int) hearts;
System.out.println("Сердечек: " + hearts);
System.out.println("Полных сердечек: " + fullHearts);
```
</div>
