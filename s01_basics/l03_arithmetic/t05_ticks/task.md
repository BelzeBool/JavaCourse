# Задача: тики во время

Minecraft отсчитывает время в <span class="k-term" title="Шаг игрового времени: 20 тиков — одна секунда">тиках</span>:
20 тиков — одна секунда. Стив играет в своём мире уже 200 000 тиков. Сколько это часов, минут и секунд?

## Условие

1. Объяви переменную `ticks` типа `int` со значением `200000` (без пробелов внутри числа).
2. Посчитай, сколько это полных часов, минут и секунд.
3. Напечатай одну строку:

<pre class="k-console">Время: 2 ч 46 мин 40 с</pre>

Всё считает программа из `ticks`: чисел 2, 46 и 40 в коде быть не должно — ни в вычислениях,
ни в тексте в кавычках. Проверка это посмотрит.

<div class="hint" title="С чего начать">

Сначала переведи тики в секунды: `int totalSeconds = ticks / 20;` — получится 10 000 секунд.
Дальше нужны две вещи: в часе 3600 секунд, в минуте 60.
</div>

<div class="hint" title="Как найти часы, минуты и секунды">

Это те же стаки, только «стак» — час или минута:

- часы — сколько раз 3600 целиком помещается в `totalSeconds` (`/`);
- минуты — сначала убери полные часы (`% 3600`), а то, что осталось, раздели на 60;
- секунды — остаток от деления на 60 (`% 60`).
</div>

<div class="hint" title="Минут получается 166">

166 — это все минуты сразу, вместе с теми, что уже ушли в часы. Сначала отрежь полные часы
остатком, потом дели: `totalSeconds % 3600 / 60`. Знаки `%` и `/` одного уровня, поэтому Java
считает их слева направо.
</div>

<div class="hint" title="Решение целиком">

```java
int ticks = 200000;
int totalSeconds = ticks / 20;
int hours = totalSeconds / 3600;
int minutes = totalSeconds % 3600 / 60;
int seconds = totalSeconds % 60;
System.out.println("Время: " + hours + " ч " + minutes + " мин " + seconds + " с");
```
</div>
