# Задача: три строки

Теперь сам. Внутри метода `main` пусто — вместо кода там комментарий `// Напиши код здесь`.
Замени его на команды, которые напечатают ровно такой текст:

<pre class="k-console">Привет, Майнкрафт!
Меня зовут Стив.
Сегодня я построю дом.</pre>

Каждая строка — отдельная команда `System.out.println(...)`.

<div class="hint" title="Как набирать быстрее">

В IntelliJ напиши `sout` и нажми **Tab** — появится `System.out.println();`
с курсором между скобками. Останется только вписать текст в кавычках.
</div>

<div class="hint" title="Check говорит, что строка отличается">

Сравни посимвольно: запятая после «Привет», точки в конце второй и третьей строки,
заглавные буквы. Проверка точная — как пароль.
</div>

<div class="hint" title="Решение целиком">

```java
System.out.println("Привет, Майнкрафт!");
System.out.println("Меня зовут Стив.");
System.out.println("Сегодня я построю дом.");
```
</div>
