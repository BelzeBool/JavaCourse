# Вопрос: сколько стрел?

У скелета-лучника в колчане стрелы. Посчитай без запуска:

```java
int arrows = 10;
arrows = arrows - 3;
arrows += 5;
arrows++;
System.out.println(arrows);
```

**Что напечатает программа?**

<div class="hint" title="Как считать, чтобы не запутаться">

Возьми листок и после каждой строки записывай, что сейчас лежит в `arrows`. Так программисты
проверяют код в уме — это называется «трассировка».
</div>
