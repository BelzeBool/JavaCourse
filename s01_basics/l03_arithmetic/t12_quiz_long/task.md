# Вопрос: как сохранить большое число?

Стив хочет узнать, сколько блоков в квадрате мира 50 000 на 50 000 — если смотреть сверху.
Это 2 500 000 000: больше, чем помещается в `int`.

```java
int side = 50000;
```

**Какая строка сохранит правильное число?**

Выбери вариант и нажми **Check**. В редакторе все четыре варианта, у каждого своя переменная:
`a`, `b`, `c`, `d`. После ответа запусти программу и сравни. Строка с `d` закомментирована — убери
`//` и посмотри, что скажет Java.

<div class="hint" title="Как рассуждать">

Правая часть считается раньше, чем результат кладётся в сундук. Посмотри, какого типа числа
в момент умножения. И вспомни, что Java делает с длинным числом без `L`.
</div>
