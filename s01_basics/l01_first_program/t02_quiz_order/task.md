# Вопрос: в каком порядке?

Стив составил себе план на утро и записал его в программу:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("3. Иду в шахту");
        System.out.println("1. Ставлю верстак");
        System.out.println("2. Крафчу кирку");
    }
}
```

**Какая строка появится в консоли первой?**

Сначала ответь в уме, потом выбери вариант и нажми **Check**.
Этот же код открыт в редакторе — после ответа можешь запустить его и убедиться.
