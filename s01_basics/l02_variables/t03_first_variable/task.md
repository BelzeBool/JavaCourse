# Задача: первая переменная

Стив нашёл в шахте 12 алмазов. Запишем это в программу.

## Условие

1. Объяви переменную `diamonds` типа `int` и положи в неё `12`.
2. Напечатай строку `Алмазов: 12` двумя командами:
   - `print` печатает текст `Алмазов: ` (с пробелом в конце);
   - `println` печатает переменную `diamonds`.

Должно получиться:

<pre class="k-console">Алмазов: 12</pre>

Проверка посмотрит не только на вывод, но и на код: число 12 должно печататься **из переменной**.

<div class="hint" title="Как записать объявление">

Шаблон: `тип имя = значение;` Тип — `int`, имя — `diamonds`, значение — `12`.
</div>

<div class="hint" title="Печатается слово diamonds, а не число">

Убери кавычки вокруг `diamonds` в `println`. В кавычках — текст, без кавычек — имя переменной.
</div>

<div class="hint" title="Решение целиком">

```java
int diamonds = 12;
System.out.print("Алмазов: ");
System.out.println(diamonds);
```
</div>
